# **YouTube Comments Pager - README**

## **1. プロジェクト概要**

「YouTube Comments Pager」は、YouTube Data APIから取得したRAW形式のJSONデータ（動画情報、チャンネル情報、コメントスレッド）を読み込み、整形されたHTMLページ（index.html）として出力するPythonスクリプトです。このツールは、特定のYouTube動画のコメントをオフラインで閲覧したり、カスタマイズ可能な形式でアーカイブしたりすることを目的としています。

生成されるHTMLページは表示専用であり、コメントの投稿機能やインタラクティブな要素は含まれません。

**バージョン**: 1.0

## **2. 機能**

* 指定された動画IDに対応する動画情報（タイトル、説明、サムネイル、公開日時）を表示します。
* 動画のチャンネル情報（アイコンとタイトル）を表示します。
* コメントデータ（トップレベルコメントと返信コメント）をツリー形式で整形して表示します。
* 親コメントと返信コメントの両方でコメント投稿者のチャンネルアイコンを表示します。
* pager-template-maker ツールと連携し、表示する各要素（動画タイトル、動画チャンネル情報、説明、サムネイル、動画メタ情報、コメント投稿者名、コメント本文、コメントメタ情報、返信コメントの各要素）の表示/非表示をカスタマイズできます。
* **ファイルダイアログを使って、youtube_data_<動画ID>_<YYYY-MM-DD_HH_MM_SS> 形式の動画データフォルダを直接選択して処理できます。**
* **生成された index.html と static フォルダは、選択した動画データフォルダ内に配置されます。**

## **3. 使用方法**

### **3.1. 前提条件**

* Python 3.x
* pip (Pythonのパッケージインストーラ)
* 以下のPythonライブラリ: jinja2, tkinter (通常Pythonに標準で含まれていますが、システムによっては別途インストールが必要な場合があります)

```bash
pip install jinja2
```

tkinter は通常Pythonに標準で含まれています。Linux環境などで不足している場合は、OSのパッケージマネージャーでインストールしてください（例: `sudo apt-get install python3-tk）。

### **3.2. 必要なフォルダとファイルの配置**

PyInstallerでビルドされた実行ファイルを使用する場合、実行ファイル（main.exeなど）があるディレクトリの直下に、以下のフォルダとファイルを配置してください。

* **動画データフォルダ**: `youtube_data_<動画ID>_<YYYY-MM-DD_HH_MM_SS>` 形式（以前の `youtube_data_<動画ID>_<YYYY-MM-DD>` 形式も受け付けます）。このフォルダ内に、以下のJSONファイルを配置します。
  * `comments_raw_<動画ID>.json`（必須）
  * `comment_replies_raw_<動画ID>.json`（返信Rawデータが保存されている場合）
  * `video_info_raw_<動画ID>.json`（任意）
  * `channel_info_raw_<チャンネルID>.json`（任意）
  * **注意**: JSONファイルは、YouTube Data APIから直接取得したRAWデータ形式である必要があります。コメントスレッドデータは、commentThreads.list のRawレスポンスページを配列に格納し、各ページが `items` キーを持つ形式を想定しています。返信データは `parent_id` と `raw_responses` を持つレコードの配列で、親コメントIDにより関連付けられます。
  * **推奨**: これらのフォルダは、以前からの慣例として `rawdata` フォルダの直下に作成することを推奨します。ファイル選択ダイアログの初期ディレクトリが `rawdata` に設定されます。
* **templates フォルダ**
  * `templates/pager-template.html`（デフォルトテンプレート）
  * `templates/example.html`（カスタマイズされたテンプレートがあれば）
* **static フォルダ**
  * `static/css/style.css`
* **default フォルダ**
  * `default/dummy_comments.json`
  * `default/dummy_video_info.json`
  * `default/dummy_channel_info.json`
  * `default/pager-template.html`
  * `default/style.css`
  * （これらのファイルは、pager-template-maker の default フォルダからコピーしてください。）

Pythonスクリプトとして直接実行する場合（開発用）は、プロジェクト直下に上記のフォルダ構造（rawdata, templates, static, default）を作成し、それぞれのファイルを配置してください。動画データフォルダは `rawdata` 内に作成することを推奨します。

コメントスレッドRawファイルは複数ページを含む場合があります。ページャーは各ページの `items` を処理します。返信Rawファイルは `parent_id` と `raw_responses` を持つレコードのリストです。返信Rawファイルが存在しない場合、親スレッドRawに含まれる返信のみ表示します。コメントスレッドRawファイルが欠落またはJSON不正の場合は、ダミーコメントへ置き換えずエラーとして扱います。

### **3.3. HTMLページの生成**

1. **テンプレートのカスタマイズ（任意）**: 表示要素をカスタマイズしたい場合は、pager-template-maker ツールを使用してください。GUIツールで表示項目を調整した後、「HTML保存」ボタンをクリックして `example.html` を保存してください。また、pager-template-maker の `default` フォルダの内容を、ページャーの `default` フォルダにコピーしてください。
2. **main.py の実行**:
   * Pythonスクリプトとして直接実行する場合、プロジェクトディレクトリで以下を実行します。
     ```bash
     python main.py
     ```
   * PyInstallerでビルドされた実行ファイルを使用する場合は、実行ファイル（例: main.exe）を直接実行します。

プログラムが起動すると、**「動画データフォルダを選択してください」というファイルダイアログが表示されます。** JSONデータが格納されている動画データフォルダを選択してください。

### **3.4. 生成されたHTMLの確認**

スクリプトの実行後、**選択した動画データフォルダの直下に** `index.html` が生成され、`static` フォルダがコピーされます。この `index.html` ファイルをウェブブラウザで開いて、整形されたコメントページを確認してください。

## **4. PyInstallerでのビルド方法（頒布アーカイブ作成）**

youtube-comments-pager を実行可能ファイルとして配布するには、PyInstallerを使用します。

### **4.1. PyInstallerのインストール**

```bash
pip install pyinstaller
```

### **4.2. ビルドコマンド**

プロジェクトディレクトリで以下を実行します。

```bash
pyinstaller --onefile --windowed main.py
```

**コマンドの説明**:

* `--onefile`: 単一の実行可能ファイルを生成します。
* `--windowed` または `-w`: コンソールウィンドウを表示しません（GUIアプリケーションの場合に推奨）。tkinterのファイルダイアログを使用する場合、このオプションを使用することで、バックグラウンドのコンソールウィンドウが表示されなくなります。
* `--add-data` オプションは使用しません。必要なデータフォルダ（templates, static, default）は、実行ファイルとは別に配置する必要があります。

### **4.3. 生成されるファイル**

ビルドが成功すると、`dist` ディレクトリ内に実行可能ファイル（例: main.exe または main）が生成されます。

### **4.4. 頒布時の注意点**

生成された実行可能ファイルは、外部の `templates`、`static`、`default` フォルダに依存します。読み込むRAWデータも動画データフォルダとして、実行ファイルとは別に存在する必要があります。配布する際は、上記「3.2. 必要なフォルダとファイルの配置」に従って、これらのフォルダとファイルを配置する必要があることを明確に伝えてください。

## **5. テスト（開発時）**

プロジェクトのルートディレクトリから、コメントRawデータのページ処理と親子紐付けを確認できます。

```bash
python -m unittest discover -s tests -t . -v
```

テストでは、以下を確認します。

* 動画データフォルダ名から動画IDを抽出する処理（現行日時付き形式と旧日付のみ形式）
* コメントスレッドRawの複数ページ処理
* 返信Rawの複数ページ処理と親コメントIDによる紐付け
* 返信Rawがない場合や返信ページのitemsが空の場合のインライン返信へのフォールバック
* 正常な空コメントリストと、欠落・不正・構造不一致の区別

**確認済みテスト結果（2026-11-27）**: このブランチで上記コマンドを実行し、10件すべて成功（Ran 10 tests / OK）したことを確認しました。実データ一式を使ったHTML生成確認は、別途実施が必要です。

## **6. 注意事項**

* このツールは、YouTube Data APIから取得済みのRAWデータを使用します。APIキーは不要です。
* コメント投稿機能は含まれていません。表示専用です。
* JSONデータのフォーマットがYouTube Data APIの標準形式と異なる場合、正しく動作しない可能性があります。
* **選択するフォルダ名は `youtube_data_<動画ID>_<YYYY-MM-DD_HH_MM_SS>` または旧形式の `youtube_data_<動画ID>_<YYYY-MM-DD>` に従う必要があります。** 異なる名前のフォルダを選択した場合、エラーメッセージが表示され、プログラムが終了します。
